# TODO Manager

## Description
A web application designed for creating and managing personalized to-do lists for each user. An old project from my time as a student.

## Tech Stack
- MongoDB: Database
- Express.js: Server-side routing
- React: Dynamic frontend user interface
- Node.js: Runtime environment and dependency management

## Key Features
- User Authentication: Logged-in users can manage their personal tasks.
- Task Management: Add and delete custom tasks.
- Task Details: Each task includes a title, description, and a due date.

## How to Run the Project

Navigate to both the `backend` and `frontend` directories and install the dependencies:

```bash
npm install
```

Then start the application in both directories (`backend` and `frontend`):

```bash
npm start
```
